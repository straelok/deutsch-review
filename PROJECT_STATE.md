# Project state

## Текущее состояние

- `Worttrieb` — персональное Flutter-приложение для Android и Windows.
  Постоянный Android ID: `io.github.straelok.deutschreview`.
- Основной источник данных — локальная SQLite-база схемы 13. Приложение работает
  без сети; синхронизация Supabase по нормализованному нику является отдельным
  необязательным слоем. Формат снимка синхронизации — версия 3; импорт старых
  снимков версий 1 и 2 сохранён.
- Реализованы двуязычный интерфейс, адаптивная тёмная тема, словарь, дневные
  занятия, грамматические темы, статистика, локальные уведомления и импорт /
  экспорт слов через JSON.
- В словарном занятии «немецкий → русский» доступна необязательная подсказка:
  до ответа она раскрывает примеры употребления слова, разделённые в данных `;`.
  У существительных рядом с немецким словом показывается компактная форма
  множественного числа, а после правильного ответа — все варианты перевода.
- Для направления «русский → немецкий» доступен отдельный лёгкий режим как для
  всех активных, так и только для важных слов:
  ошибочная попытка показывает правильное написание и оставляет то же слово,
  пока пользователь не введёт его верно. Первая ошибка влияет на статистику,
  успешное исправление — нет; прогресс занятия растёт только после правильного
  ответа.
- В словаре слова можно временно отметить важными. По запросу доступны отдельные
  занятия в обоих направлениях только по этим словам; все отметки можно снять
  одной кнопкой с обязательным подтверждением. Начатая очередь при этом
  сохраняется.
- Нажатие на слово в словаре открывает отдельную карточку только для чтения с
  переводом, метаданными, примерами, заметкой и статистикой. Редактирование
  остаётся отдельным действием в меню слова.
- Фоновая синхронизация сообщает интерфейсу только о фактически изменившихся
  данных. Словарь обновляет данные без полноэкранного индикатора и сохраняет
  текущую позицию прокрутки.
- В пользовательском JSON `worttrieb-words-2026-09-26.json` дополнительные
  простые примеры добавлены всем 134 словам с двумя и более ошибками по полному
  синхронизированному снимку профиля `strael` из 1063 попыток.
- Пользовательский JSON содержит 812 слов. По материалам уроков 1–7 и отдельным
  дополнительным листам добавлены отсутствовавшие слова и выражения с русскими
  переводами, формами и примерами. Для подготовки к диктанту важны только 49
  позиций словаря урока 7. У остальных слов отметки явно сняты. В словаре также
  есть учебные и грамматические термины, используемые на уроках.
- Локальные фотографии учебника, рабочей тетради, словаря и дополнительных
  листков организованы в `materialien` по источнику; словарь, учебник и рабочая
  тетрадь обработаны до урока 7. Изображения
  не публикуются в Git и используются только как источник для новых материалов.
- Количество ежедневных занятий и заданий отдельно настраивается для слов в
  обоих направлениях, чисел и грамматики; исходные значения — `3 × 20`,
  `3 × 20`, `2 × 20` и `2 × 10`. Очередь, прогресс и версия учебного каталога
  сохраняются.
- План показывает четыре изначально свёрнутые категории: два направления слов,
  грамматику и прочее. Важные слова находятся в выделенных подразделах внутри
  направлений, а избранная грамматика — внутри грамматики. Категория служит
  только сворачиваемым контейнером со сводным счётчиком; кнопки запуска,
  продолжения и добавления находятся на карточках режимов внутри неё.
- В категории «Прочее» доступно сопоставление карточек: 24 слова разбиваются на
  три доски по восемь уникальных пар. Успехи не улучшают статистику слова,
  первая ошибка на доске учитывается.
- В «Прочем» доступен выбор перевода: 20 вопросов, четыре варианта и чередование
  направлений после каждого ответа. Поддерживаются клавиши `1`–`4`, `Esc` и
  `Enter`; успех не улучшает статистику слова, ошибка учитывается.
- В каждом направлении перевода есть собственный марафон. Он хранит
  синхронизируемый прогресс между днями, фиксирует все активные слова на момент
  старта и поддерживает подтверждаемый сброс без удаления истории ответов.
- Android-напоминания можно отключить и настроить до пяти времён; значения по
  умолчанию — 13:30, 16:30 и 19:30.
- Настройки сохраняются автоматически сразу после изменения; нижняя кнопка
  сохранения и подтверждение при выходе не используются. Содержимое экрана
  учитывает нижнюю безопасную область Android и не перекрывается системной

- Экран статистики разделён навигацией «Сегодня» / «За всё время». В каждом
  периоде отдельно показаны оба направления перевода слов, цифры и грамматика:
  попытки, правильные ответы, ошибки и точность.
- Приоритет материала определяется только успешностью последних десяти ответов.
  В настройках пользователь самостоятельно задаёт максимальный вес проблемных
  слов целым числом от 1 до 1 000 000; исходное значение — 10. Настройка
  применяется только к словарным занятиям. FSRS и рейтинги `Again` / `Hard` /
  `Good` / `Easy` не используются.
- Очередь слов фиксируется при старте занятия и затем только сокращается на
  отвеченные карточки. Синхронизация не может откатить статус или счётчик

## Ключевые решения

- Flutter/Dart, Android и Windows, SQLite, offline-first.
- Учебные материалы создаются специально для приложения по последовательности
  стандартного издания Hueber *Schritte plus Neu 1* A1.1 без копирования
  страниц и упражнений.
- Импорт обновляет или добавляет записи, не удаляя отсутствующие в файле;
  локальные ID, дата добавления и история ответов сохраняются.
- Пользовательский пример слова может быть справкой, но не становится
  автоматически проверяемым заданием.
- Знание ника даёт доступ к синхронизируемому профилю; пользователь принял этот
  риск. Локальная работа от синхронизации не зависит.
- Windows-сборка для передачи пользователю создаётся только через
  `tool/package_windows.ps1`, вместе со всеми DLL и папкой `data`.
- Новые зависимости добавляются только после проверки актуальности, лицензии и
  поддержки Android/Windows.

  разработки.
- Настройки плана и напоминаний локальны для устройства и не входят в
  синхронизируемый профиль.
