# Project state

## Текущее состояние

- `Worttrieb` — персональное Flutter-приложение для Android и Windows с
  немецким и русским интерфейсом. Android ID:
  `io.github.straelok.deutschreview`.
- Приложение работает offline-first. Основной источник — локальная SQLite-база
  схемы 14; необязательная синхронизация Supabase по нормализованному нику
  использует снимок v3 и принимает старые версии 1–2.
- Реализованы словарь, настраиваемый дневной план, грамматика, статистика,
  уведомления и импорт / экспорт слов через JSON. Настройки сохраняются сразу.
- Словарная практика поддерживает оба направления перевода, лёгкий режим с
  обязательным исправлением ошибки, запуск тех же режимов только по важным
  словам, сопоставление карточек, выбор ответа и постоянные марафоны. Ошибочное
  слово возвращается после нескольких других карточек; исходная очередь
  уникальна, фиксируется при старте и синхронизацией не откатывается.
- Словарь содержит 920 карточек по урокам 1–8 и дополнительным материалам.
  Карточка слова показывает формы, переводы, примеры, заметки и статистику;
  редактирование выполняется отдельным действием. Актуальное правило состава
  важных слов задано в `AGENTS.md`.
- Грамматика содержит 36 тем и 2105 оригинальных упражнений по программе
  *Schritte plus Neu 1–2* A1.1–A1.2. Практика доступна только для отмеченной изученной
  темы при наличии подходящего активного слова; `sein` и `haben` отделены от
  регулярного Präsens.
- Общий учебный каталог поставляется независимо от пользовательской
  синхронизации: gzip-пакет из Supabase Storage проверяется по размеру и
  SHA-256 и активируется атомарно. Незавершённое занятие закреплено за своей
  `content_version`; при сбое остаётся рабочая локальная или встроенная версия.
- Текущий опубликованный каталог — `2026.10.21.1`: 36 тем,
  2105 упражнений, 64 335 байт в gzip, SHA-256
  `e966b3f4f95b8d0a7c264e87905201241f673a30a5979436ff60ff375ed08635`.
- Источники Kursbuch, Arbeitsbuch и Wörterbuch обработаны до урока 8.
  Дополнительные листы хранятся отдельно. Исходники находятся локально в
  `materialien`, обработанные — в `materialien/Verarbeitet`; журнал — в
  `materialien/VERARBEITET.md`.
- Этапы 1–7 `ROADMAP.md` завершены. Новые грамматические темы добавляются только
  после сообщения пользователя о фактически пройденном материале.

## Ключевые решения

- Flutter/Dart, Android и Windows, SQLite, offline-first; синхронизация не нужна
  для основной работы.
- Учебный материал хранится как данные и создаётся специально для приложения по
  *Schritte plus Neu 1–2* A1.1–A1.2 без копирования упражнений учебника.
- Изменения грамматических JSON доставляются установленным приложениям упаковкой
  и публикацией новой версии каталога; Android/Windows для этого не собираются.
- Импорт слов добавляет и обновляет записи без удаления отсутствующих; сохраняет
  локальные ID, дату добавления и историю ответов.
- Приоритет слов определяется последними десятью ответами. FSRS и рейтинги
  `Again` / `Hard` / `Good` / `Easy` не используются.
- Знание ника даёт доступ к синхронизируемому профилю; пользователь принял риск.
- Новые зависимости требуют проверки актуальности, лицензии и Android/Windows.
  Windows-сборка передаётся только полным комплектом из
  `tool/package_windows.ps1`.

## Открытые ограничения

- Локальная Windows-база пользователя повреждена; полная статистика получена из
  синхронизированного профиля `strael` с разрешения пользователя.
- `flutter_timezone` 5.1.0 предупреждает о старом подключении Kotlin Gradle
  Plugin; совместимость нужно проверить при следующем обновлении Flutter.
- Windows Developer Mode остаётся включённым до завершения разработки.
- Настройки плана и напоминаний локальны и не синхронизируются.
