## Принятые решения

- Flutter/Dart с поддержкой Android и Windows.
- SQLite и локальная база как основной источник данных.
- Offline-first; синхронизация Supabase по нику входит в этап 3, но не нужна для
  основной локальной работы.
- Учебные данные импортируются и редактируются без перекомпиляции.
- FSRS и рейтинги ответов полностью исключены. Приоритет определяется долей
  правильных среди последних десяти ответов по простой весовой формуле.
- Подробные требования хранятся в `PRODUCT_SPEC.md`, рабочие правила — в `AGENTS.md`.
- Название приложения — `Worttrieb`: ассоциация с ростом словарного запаса и
  внутренней тягой к изучению языка.
- Постоянный идентификатор Android-приложения —
  `io.github.straelok.deutschreview`.
- Общие поля учебного элемента хранятся в столбцах SQLite, различающееся
  содержимое — в валидном JSON.
- На локальный день создаются пять занятий по 20 ответов. Прогресс и очередь
  незавершённого занятия сохраняются для продолжения после перезапуска.
- Версия схемы хранится в `PRAGMA user_version`; миграции выполняются только
  вперёд, по одной версии и в транзакции, без автоматического сброса данных.
- Число новых слов не ограничивается приложением и следует программе DAA.
- Проблемные слова получают больший вес по последним десяти ответам; слово без
  истории считается имеющим 0% успешности.
- Android напоминает о незавершённых занятиях в 13:30, 16:30 и 19:30 по
  локальному времени устройства.
- Синхронизация использует только нормализованный ник без почты и пароля. Знание
  ника даёт полный доступ к профилю; пользователь явно принял этот риск.
- Очередь повторений не блокирует остальные функции приложения.
- После этапа интерфейса словаря предоставляется запускаемая Windows-сборка для
  ручной проверки до продолжения разработки.
- После завершения всей разработки нужно напомнить пользователю отключить
  Windows Developer Mode, включённый для сборки Flutter-плагинов.
- Каждая новая пользовательская функция реализуется вместе с доступным UI в
  том же этапе; наличие только backend-кода не считается завершением функции.
- Форма материала не содержит уровень, урок, тему, источник и отметку
  изученности. Любое добавленное слово сразу участвует в повторениях; UI
  показывает неизменяемую дату добавления.
