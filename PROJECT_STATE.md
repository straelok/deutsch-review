# Project state

## Текущее состояние

- `Worttrieb` — персональное Flutter-приложение для Android и Windows.
  Постоянный Android ID: `io.github.straelok.deutschreview`.
- Основной источник данных — локальная SQLite-база схемы 9. Приложение работает
  без сети; синхронизация Supabase по нормализованному нику является отдельным
  необязательным слоем. Формат снимка синхронизации — версия 2.
- Реализованы двуязычный интерфейс, адаптивная тёмная тема, словарь, дневные
  занятия, грамматические темы, статистика, локальные уведомления и импорт /
  экспорт слов через JSON.
- В словарном занятии «немецкий → русский» доступна необязательная подсказка:
  до ответа она раскрывает примеры употребления слова, разделённые в данных `;`.
- В словаре слова можно временно отметить важными. По запросу доступны отдельные
  занятия в обоих направлениях только по этим словам; все отметки можно снять
  одной кнопкой с обязательным подтверждением. Начатая очередь при этом
  сохраняется.
- В пользовательском JSON `worttrieb-words-2026-09-26.json` дополнительные
  простые примеры добавлены всем 134 словам с двумя и более ошибками по полному
  синхронизированному снимку профиля `strael` из 1063 попыток.
- Пользовательский JSON содержит 336 слов. Лексика с предоставленных страниц
  уроков 2 и 3 и дополнительного листка (121 карточка) отмечена как важная;
  39 отсутствовавших слов добавлены с переводами, формами и примерами. Ещё 26
  карточек охватывают учебные и грамматические термины, используемые на уроках.
- Количество ежедневных занятий и заданий отдельно настраивается для слов в
  обоих направлениях, чисел и грамматики; исходные значения — `3 × 20`,
  `3 × 20`, `2 × 20` и `2 × 10`. Очередь, прогресс и версия учебного каталога
  сохраняются.
- Важные уроки можно скрыть без удаления отметок и начатых очередей. План
  показывает только категории с кнопками запуска, продолжения и добавления,
  без раскрывающегося списка отдельных занятий.
- Android-напоминания можно отключить и настроить до пяти времён; значения по
  умолчанию — 13:30, 16:30 и 19:30.
- Экран статистики разделён навигацией «Сегодня» / «За всё время». В каждом
  периоде отдельно показаны слова, цифры и грамматика: попытки, правильные
  ответы, ошибки и точность.
- Приоритет материала определяется только успешностью последних десяти ответов.
  FSRS и рейтинги `Again` / `Hard` / `Good` / `Easy` не используются.
- Очередь слов фиксируется при старте занятия и затем только сокращается на
  отвеченные карточки. Синхронизация не может откатить статус или счётчик
  занятия на более раннее состояние.
- Личные местоимения и регулярные глаголы в Präsens объединены в одну тему и
  общий банк заданий. Грамматическая практика доступна только для отмеченной
  изученной темы при наличии подходящего активного слова. `sein` и `haben` —
  отдельные темы.
- Учебный контент хранится как данные. Общий каталог поставляется отдельным
  версионируемым gzip-пакетом из Supabase Storage с проверкой размера и SHA-256,
  атомарной активацией и встроенным offline-fallback.
- Изменения исходных JSON грамматики доставляются установленным приложениям
  после упаковки и публикации новой версии каталога в Supabase. Это не требует
  сборок Android/Windows; новая сборка нужна только для обновления встроенного
  offline-fallback или изменения поведения приложения.
- Локальный fallback и опубликованный серверный каталог `2026.10.04.3` содержат
  1669 упражнений, 38 509 байт в gzip, SHA-256
  `6a9ed71915d52a03c2f450173bcd9c73b76bcf66d8ed58d679161a147bd02c57`.
- Незавершённое занятие закрепляется за своей `content_version`; нужная версия
  удерживается локально и при необходимости загружается по неизменяемому адресу.
- Этапы 1–7 из `ROADMAP.md` завершены. Новые грамматические темы добавляются
  только после сообщения пользователя о фактически пройденном материале.

## Ключевые решения

- Flutter/Dart, Android и Windows, SQLite, offline-first.
- Учебные материалы создаются специально для приложения по последовательности
  стандартного издания Hueber *Schritte plus Neu 1* A1.1 без копирования
  страниц и упражнений.
- Импорт обновляет или добавляет записи, не удаляя отсутствующие в файле;
  локальные ID, дата добавления и история ответов сохраняются.
- Пользовательский пример слова может быть справкой, но не становится
  автоматически проверяемым заданием.
- Знание ника даёт доступ к синхронизируемому профилю; пользователь принял этот
  риск. Локальная работа от синхронизации не зависит.
- Windows-сборка для передачи пользователю создаётся только через
  `tool/package_windows.ps1`, вместе со всеми DLL и папкой `data`.
- Новые зависимости добавляются только после проверки актуальности, лицензии и
  поддержки Android/Windows.

## Открытые ограничения

- Локальная Windows-база пользователя повреждена: полная статистика была взята
  из синхронизированного профиля `strael` с явного разрешения пользователя.
- `flutter_timezone` 5.1.0 предупреждает о старом способе подключения Kotlin
  Gradle Plugin. Текущая Android-сборка работает; совместимость нужно проверить
  при следующем обновлении Flutter.
- Windows Developer Mode остаётся включённым до окончательного завершения
  разработки.
- Настройки плана и напоминаний локальны для устройства и не входят в
  синхронизируемый профиль.
