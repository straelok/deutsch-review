## 2.1. Версия для первого ручного тестирования — завершён

- [x] Переключать весь интерфейс между немецким и русским языками и сохранять
  выбранный язык локально.
- [x] Добавить поиск по немецкому слову и русскому переводу.
- [x] Показывать неизменяемую дату и время добавления слова.
- [x] Добавить мягкое удаление с подтверждением и возможностью отмены.
- [x] Предупреждать о дубликате слова или существительного перед сохранением.
- [x] Реализовать базовую сессию повторения изученных слов: перевод на русском,
  ввод ответа на немецком, автоматическая проверка и повтор ошибок в пределах
  текущей сессии без ручного рейтинга.
- [x] Показывать простую статистику: попытки, правильные ответы, ошибки, точность и
  список наиболее проблемных слов.
- [x] Сохранять попытки и настройки в SQLite с миграцией, не блокировать остальные
  разделы незавершённой сессией.
- [x] Перед миграцией существующей базы автоматически создавать резервную копию.
- [x] Подготовить новый Windows-архив и сценарий ручной проверки с перезапуском.
- [x] Добавить необязательные заметку и пример использования в форму, карточку,
  поиск и обратную связь после ответа.

## 3. Вертикальная сессия повторения

- [ ] Проверить и зафиксировать чистую Dart-реализацию FSRS с MIT-лицензией,
  обернув её существующим интерфейсом планировщика.
- [ ] Добавить миграцию расписаний без сброса слов и истории попыток.
- [ ] Автоматически преобразовывать результат ответа в сигнал FSRS: ошибка —
  `Again`, правильный ответ после ошибки в сессии — `Hard`, правильный ответ с
  первой попытки — `Good`; не показывать пользователю кнопки рейтинга.
- [ ] Настроить `desired retention = 0.95`, сначала выдавать запланированные
  повторения, затем все новые слова без дневного лимита.
- [ ] Повышать приоритет слов с ошибками и возвращать ошибочное слово только
  после других карточек, когда это возможно.
- [ ] Сохранять событие и новое расписание атомарно; восстанавливать очередь
  после перезапуска приложения.
- [ ] Обновить UI разделов `Heute`, `Lernen` и `Statistik`: показать объём
  очереди, прогресс, ближайшее повторение и проблемные слова, не блокируя
  навигацию.
- [ ] Покрыть миграцию, расписание и очередь тестами с управляемым временем;
  собрать Android и Windows для ручной проверки этапа.

## 4. Обмен данными

- Утвердить версию формата.
- Реализовать предварительный просмотр и проверку JSON.
- Добавить импорт из файла и буфера, экспорт и резервное копирование.
- Затем добавить CSV и обнаружение дубликатов.

## 5. Качество интерфейса

- Адаптивная тёмная тема для Android и Windows.
- Доступность, контраст и крупные области нажатия.
- Относящиеся к основным сценариям тесты.
