## 3. Ежедневные занятия, напоминания и синхронизация

### 3.1. Локальная система занятий

- [ ] Добавить миграцию с резервной копией для дневного плана и состояния
  незавершённого занятия без потери слов и истории ответов.
- [ ] Удалить из доменной логики FSRS и рейтинги `Again` / `Hard` / `Good` /
  `Easy`; хранить только правильность ответа.
- [ ] Рассчитывать успешность слова по последним десяти ответам; слово без
  ответов считать имеющим 0% успешности.
- [ ] Использовать простой вес `1 + round((1 - успешность) * 9)`: проблемные
  слова встречаются чаще, но слова со 100% не исключаются полностью.
- [ ] Создавать на каждый локальный день пять занятий по 20 ответов; разрешить
  выбирать их в любом порядке и повторно запускать завершённое как
  дополнительное.
- [ ] Сохранять точный прогресс и очередь незавершённого занятия, чтобы его
  можно было продолжить после перезапуска приложения.
- [ ] Обновить UI `Heute`, `Lernen` и `Statistik` вместе с логикой занятий,
  сохранив свободную навигацию по приложению.
- [ ] Покрыть приоритет, дневной план и продолжение занятия тестами.

### 3.2. Локальные уведомления Android

- [ ] Проверить и зафиксировать поддерживаемую библиотеку уведомлений.
- [ ] Запрашивать системное разрешение без блокировки основной работы.
- [ ] Напоминать в 13:30, 16:30 и 19:30 по времени устройства, только если
  остались незавершённые обязательные занятия.
- [ ] После выполнения пяти занятий отменять оставшиеся уведомления дня;
  нажатие на уведомление открывает `Heute`.

### 3.3. Синхронизация Supabase по нику

- [ ] Подключить бесплатный Supabase через заменяемый слой, сохранив SQLite
  единственным локальным источником данных и полную работу без сети.
- [ ] Использовать нормализованный уникальный ник без почты и пароля: новый ник
  создаёт профиль, существующий загружает его данные.
- [ ] Разрешить в нике латинские буквы, цифры, `_` и `-`, длина 3–24 символа;
  игнорировать регистр и внешние пробелы.
- [ ] Синхронизировать слова, мягкие удаления, неизменяемые ответы, дневные
  занятия, незавершённую очередь и необходимые настройки.
- [ ] Закрыть прямой доступ и перечисление облачных строк, но считать знание
  ника полным доступом к профилю; этот риск принят пользователем.
- [ ] Разрешать конфликты детерминированно: слова по `updated_at`, ответы по
  UUID только добавлением, а завершённое занятие не откатывать назад.
- [ ] Добавить автоматическую синхронизацию при старте, изменениях и
  восстановлении сети, а также ручную кнопку, статус и время последнего успеха.
- [ ] Проверить offline-first поведение, повтор после ошибок и обмен между
  Android и Windows.

### 3.4. Завершение этапа

- [ ] Собрать Android и Windows, установить APK на телефон и подготовить
  сценарий ручной проверки всего этапа 3.
