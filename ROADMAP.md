# Roadmap

## 1. Каркас — завершён

- [x] Проверить инструменты Flutter, Android и Windows.
- [x] Создать приложение и базовую навигацию.
- [x] Настроить анализатор и минимальные тесты.

## 2. Локальные данные

- [x] Определить доменные модели и схему SQLite.
- [x] Добавить миграции и репозитории.
- Реализовать ручное добавление и редактирование материала.

## 3. Вертикальная сессия повторения

- Выбрать и изолировать реализацию FSRS.
- Реализовать очередь, показ вопроса, ввод и проверку ответа.
- Сохранять события повторения и новое расписание.

## 4. Обмен данными

- Утвердить версию формата.
- Реализовать предварительный просмотр и проверку JSON.
- Добавить импорт из файла и буфера, экспорт и резервное копирование.
- Затем добавить CSV и обнаружение дубликатов.

## 5. Качество интерфейса

- Адаптивная тёмная тема для Android и Windows.
- Доступность, контраст и крупные области нажатия.
- Относящиеся к основным сценариям тесты.

## 6. Поздние этапы

- Синхронизация с заменяемым провайдером.
- Расширенная статистика.
- Дополнительные виды упражнений.
