## 3. Ежедневные занятия, напоминания и синхронизация

### 3.1. Локальная система занятий

- [x] Добавить миграцию с резервной копией для дневного плана и состояния
  незавершённого занятия без потери слов и истории ответов.
- [x] Удалить из доменной логики FSRS и рейтинги `Again` / `Hard` / `Good` /
  `Easy`; хранить только правильность ответа.
- [x] Рассчитывать успешность слова по последним десяти ответам; слово без
  ответов считать имеющим 0% успешности.
- [x] Использовать простой вес `1 + round((1 - успешность) * 9)`: проблемные
  слова встречаются чаще, но слова со 100% не исключаются полностью.
- [x] Создавать на каждый локальный день пять занятий по 20 ответов; разрешить
  выбирать их в любом порядке и повторно запускать завершённое как
  дополнительное.
- [x] Сохранять точный прогресс и очередь незавершённого занятия, чтобы его
  можно было продолжить после перезапуска приложения.
- [x] Обновить UI `Heute`, `Lernen` и `Statistik` вместе с логикой занятий,
  сохранив свободную навигацию по приложению.
- [x] Покрыть приоритет, дневной план и продолжение занятия тестами.

### 3.1.5. Синхронизация Supabase по нику

- [x] Реализовать заменяемый клиентский слой, сохранив SQLite единственным
  локальным источником данных и полную работу без сети.
- [x] Создать бесплатный проект Supabase, применить миграцию, развернуть Edge
  Function и передать публичную конфигурацию в сборки.
- [x] Использовать нормализованный уникальный ник без почты и пароля: новый ник
  создаёт профиль, существующий загружает его данные.
- [x] Разрешить в нике латинские буквы, цифры, `_` и `-`, длина 3–24 символа;
  игнорировать регистр и внешние пробелы.
- [x] Синхронизировать слова, мягкие удаления, неизменяемые ответы, дневные
  занятия, незавершённую очередь и необходимые настройки.
- [x] Применить RLS, запрет прямого доступа и Edge Function для точного ника;
  считать знание ника полным доступом к профилю.
- [x] Разрешать конфликты детерминированно: слова по `updated_at`, ответы по
  UUID только добавлением, а завершённое занятие не откатывать назад.
- [x] Добавить автоматическую синхронизацию при старте, изменениях и
  восстановлении сети, а также ручную кнопку, статус и время последнего успеха.
- [x] Проверить offline-first поведение, повтор после ошибок и обмен между
  Android и Windows.

### 5.3. Новые темы по фактически пройденному материалу — отложен

- Новые темы курса не планируются заранее и не являются следующим этапом.
- Тема добавляется только после сообщения пользователя, что она пройдена в
  школе, вместе с объяснением, UI, банком упражнений, статистикой,
  синхронизацией и тестами.
- Последовательное заполнение всех семи уроков *Schritte plus Neu 1* A1.1
  исключено из текущего масштаба приложения.
