# Архив: оценка расхода токенов

Статус: неактивно с 19.10.2026. Эти правила сохранены только для истории и не
должны применяться в задачах проекта.

Ранее после задач с инструментами или изменениями файлов итог содержал примерное
распределение расхода токенов между проработкой задания, реализацией, тестами и
исправлениями, сборкой и публикацией. Доли указывались целыми процентами с суммой
100% и явно назывались оценкой, а не измерением. Выполнение тестов и сборок
компьютером не учитывалось — только постановка, чтение результатов и разбор
ошибок.

Правило архивировано, потому что такая оценка не опиралась на точную телеметрию
и не помогала принимать решения по проекту.
