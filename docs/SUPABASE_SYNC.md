# Supabase sync

Статус: клиент, UI, SQL-миграция и Edge Function реализованы. Миграция и
`sync-profile` развёрнуты в бесплатном проекте `hjihhrcxkpzglgfmfuzs`.

## Архитектура

- SQLite остаётся локальным источником и работает без сети.
- Клиент отправляет снимок профиля в `sync-profile` только с публичным ключом.
- Edge Function проверяет публичный ключ и точный нормализованный ник.
- Секретный ключ доступен только Edge Function и не попадает в приложение.
- Роли `anon` и `authenticated` не имеют прямого доступа к `sync_profiles`.
- Знание ника даёт полный доступ к соответствующему профилю; риск принят.

Облачный снимок версии 2 содержит слова, мягкие удаления, словарные и
грамматические попытки, отметки изученных тем и дневные занятия с их типом.
Слова и отметки тем выбираются по более позднему времени изменения, попытки
объединяются по UUID, а для обязательных занятий используется ключ
`localDate + slot`. Завершённое занятие имеет приоритет над незавершённым.

## Грамматика

Расширение этапа 5 реализовано миграцией
`supabase/migrations/202609240001_grammar_sync.sql` и развёрнуто в проекте.
Коллекции `grammarProgress` и `grammarAttempts`, тип занятия и сохранённая
очередь позволяют продолжать занятия 6 и 7 на другом устройстве с того же
места.

Встроенные объяснения и банки заданий не отправляются в Supabase: одинаковые
версии приложения обращаются к ним по стабильным ID. Старые снимки без
грамматических полей продолжают загружаться как профили без изученных
грамматических тем. Edge Function принимает форматы снимка 1 и 2, а результат
объединения сохраняет в формате 2.

## Развёртывание

1. Создать бесплатный проект в панели Supabase и сохранить пароль базы вне
   репозитория.
2. Установить Supabase CLI, выполнить `supabase login` и связать каталог с
   проектом через `supabase link --project-ref <project-id>`.
3. Выполнить `supabase db push`.
4. Выполнить `supabase functions deploy sync-profile --no-verify-jwt`.
5. Скопировать `tool/supabase_defines.example.json` в
   `tool/supabase_defines.json` и указать URL проекта и publishable key.
   Этот локальный файл исключён из Git.
6. Собирать приложение с параметром
   `--dart-define-from-file=tool/supabase_defines.json`.

Новые ключи Supabase имеют форматы `sb_publishable_...` и `sb_secret_...`.
Клиенту разрешён только publishable key. Secret key или старый service-role key
нельзя сохранять в исходниках, локальном JSON сборки или GitHub.

## Проверка

- Ввести новый ник на Windows и дождаться статуса успешной синхронизации.
- Ввести тот же ник на Android и проверить появление слов.
- Создать, изменить и удалить слово по очереди на обоих устройствах.
- Начать занятие, закрыть приложение и продолжить его на другом устройстве.
- Отметить грамматическую тему изученной и проверить на втором устройстве
  отметку, занятия 6–7 и их прогресс.
- Выполнить изменение без сети и проверить отправку после её восстановления.
