# Ручная проверка JSON-импорта и экспорта

1. Открыть `Слова` и нажать `Экспорт JSON`. Выбрать доступную папку и
   убедиться, что появился файл `worttrieb-words-YYYY-MM-DD.json`.
2. Открыть файл и проверить `format_version: 1` и массив `words` с текущими
   словами. Внутренних полей SQLite в файле быть не должно.
3. Добавить в массив новое уникальное слово без `id`, например:

   ```json
   {
     "type": "word",
     "german": "prüfen",
     "translation_ru": "проверять"
   }
   ```

4. Нажать `Импорт JSON`, выбрать изменённый файл и проверить предварительный
   итог. Подтвердить импорт: новое слово должно появиться в списке и участвовать
   в занятиях.
5. Импортировать тот же файл повторно: существующие слова должны быть
   пропущены, а дубли не созданы.
6. Попробовать файл без `format_version` или обязательного перевода: приложение
   должно показать ошибку и не добавить ни одного элемента.
7. Повторить экспорт и импорт на второй платформе. После успешного импорта
   проверить обычную синхронизацию Supabase.
