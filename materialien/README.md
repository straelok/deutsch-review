# Материалы занятий

Эта папка предназначена для фотографий и сканов учебных материалов, которые
используются как источник при пополнении словаря, правил и заданий приложения.

## Структура

- `Arbeitsbuch/Lektion-1`–`Lektion-4` — рабочая тетрадь.
- `Kursbuch/Lektion-1`–`Lektion-4` — учебник.
- `Woerterbuch/Lektion-1`–`Lektion-4` — страницы словаря и списки слов.
- `Zusaetzlich` — дополнительные листки и материалы без разделения по лекциям.

Фотографии лучше называть по странице или порядку, например `seite-012.jpg`,
`uebung-03.png` или `blatt-01.webp`. Если одна страница снята частями, удобно
добавлять суффиксы: `seite-012-a.jpg`, `seite-012-b.jpg`.

Фотографии и PDF внутри этой папки остаются локальными и игнорируются Git. В
репозитории сохраняются только структура папок и эта памятка.

При работе с материалом нужно открывать только указанную пользователем книгу и
лекцию, учитывать все относящиеся к ней изображения и создавать для приложения
собственные объяснения и упражнения, не копируя задания учебника дословно.
